Kurdish Konkan 🎮

About

Kurdish Konkan is an online Kurdish card game project.

Features

* Kurdish language interface
* Online multiplayer game
* Private rooms for friends
* Player accounts
* Game scores and leaderboard
* Mobile-friendly design
* Works toward compatibility with iPhone Safari and desktop browsers

Technology

* Next.js
* TypeScript
* React
* CSS

Getting Started

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local development URL shown in the terminal.
